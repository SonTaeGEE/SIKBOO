# 식재료를 부탁해 프로젝트
- __프로젝트 명__ : 식재료를 부탁해 (sikboo)

- __프로젝트 소개__ : 식재료 관리와 레시피 추천, 그리고 공동구매 기능을 결합하여 가정 내 식재료 낭비를 줄이고, 보다 효율적인 소비 생활을 돕는 서비스

- __프로젝트 목표__ : 사용자 개인의 식재료를 체계적으로 관리하고, 현재 가지고 있는 재료를 기반으로 레시피를 추천해주며, 필요한 재료는 주변 사람들과 공동구매할 수 있도록 도움.
- 
- __주요 기능__ :
  - 소셜로그인
  - 로그아웃
  - 내 재료 추가
  - 레시피 생성 및 목록에 표시
  - 공동구매 기능

- __개발 기간__ : 2025.10.28 ~ 2025.11.26
